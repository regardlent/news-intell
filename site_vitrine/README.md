# Site vitrine — news-intell

Ce dossier contient le **site vitrine** statique (landing page) destiné à
présenter et vendre l'application **news-intell**. Il est volontairement
indépendant : il suffit d'ouvrir `index.html` dans un navigateur.

## Fichiers
- `index.html` — structure de la landing page.
- `style.css` — charte graphique (thème sombre, accents).
- `app.js` — petites interactions (formulaire, défilement fluide).

> Les images/maquettes de démonstration sont à ajouter dans un dossier `assets/`
> selon les besoins ; le ton est volontairement orienté bénéfices.
