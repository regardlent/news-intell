# Équipe de développement — Site vitrine news-intell

## Objectif

Concevoir et maintenir un **site vitrine** attrayant pour présenter et vendre
l'application **news-intell**.

## Composition de l'équipe

| Rôle                     | Mission                       | Responsabilités                                                     |
|--------------------------|-------------------------------|----------------------------------------------------------------------|
| **Chef de produit**      | Cadrer l'offre                | Personas, proposition de valeur, parcours d'achat, indicateurs KPIs  |
| **Designer UI/UX**       | Expérience du site            | Maquettes, identité visuelle, accessibilité, responsive              |
| **Développeur front-end**| Coder le site                 | HTML/CSS/JS, performance, SEO technique                              |
| **Rédacteur / SEO**      | Fournir le contenu            | Textes persuasifs, mots-clés, balises meta, ton éditorial            |
| **Intégrateur démo/API** | Connecter la démo             | Démo interactive, formulaires, consommation de l'API JSON            |
| **QA**                   | Garantir la qualité           | Tests de parcours, compatibilité navigateurs, accessibilité          |
| **DevOps / Hébergement** | Mettre en ligne               | CI/CD, domaine, hébergement statique                                 |

## Livrables

- `site_vitrine/index.html`, `style.css`, `app.js` (site statique).
- Copies de démonstration des analyses (captures, extraits).
- Maquettes, charte couleur et ton éditorial.

## Bonnes pratiques

- Ton clair, orienté **bénéfices** (éviter le jargon).
- CTA principal : « Demander une démo ».
- Site statique **léger** pour une performance rapide.
- **Responsive** et **accessible**.
